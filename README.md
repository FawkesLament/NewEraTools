# NewEraTools

A World of Warcraft (retail) toolbox addon.

## Features

- **Raid lottery (团队抽签)**: randomly picks raid members and announces them in raid chat. Raid leader or assistants only.

## Usage

Type `/netools` or click the minimap button to open the panel.

## Development

See [AGENTS.md](AGENTS.md) for the project structure and coding rules. Run the tests with `luajit tests/run.lua`.

# NewEraTools

A World of Warcraft (retail) toolbox addon.

## Features

- **Combat log reminder**: Warns when combat logging is off in current-expansion raids or mythic dungeons; click to enable.
- **Combat timer (战斗计时)**: Floating timer for the current fight.
- **Raid lottery (团队抽签)**: Randomly picks raid members and announces them in raid chat.
- **Sszorak helper (斯索拉克)**: Mythic Venomous Abyss M5 arena map with marker sync, move timeline, and wind vent helper.

## Usage

Type `/ne2s` or click the minimap button to open the panel.
